# 🌟 Meme Hologram

Welcome to the Meme Hologram project! This is an interactive 3D particle hologram video player.

Don't worry if you have zero coding knowledge—this guide is written just for you. Follow these simple step-by-step instructions, and you'll have the hologram running on your computer in just a few minutes!

---

## 🛠️ Step 1: Install Required Software (Node.js)

To run this project, your computer needs a free software called **Node.js**. Think of it as the engine that powers this app.

1. Go to the official website: [https://nodejs.org/](https://nodejs.org/)
2. You will see two big download buttons. Click the one that says **LTS (Recommended For Most Users)**.
3. Once the download finishes, open the file and install it just like any normal program. Keep clicking "Next" and accept the default settings until it's done.

*(If you already have Node.js installed, you can skip this step!)*

---

## 📂 Step 2: Open Your Terminal

Now, you need to open a tool called the "Terminal" or "Command Prompt". It's a text box where you can type commands to your computer.

- **If you are on Windows:** 
  1. Open the folder where you saved this "Meme Hologram" project.
  2. Click on the address bar at the very top of the folder window (where it says the folder path, like `C:\Users\Downloads\Meme Hologram`).
  3. Delete all the text there, type exactly the letters `cmd`, and press **Enter**. A black window will pop up.

- **If you are on Mac:**
  1. Press `Command (⌘) + Space` to open search.
  2. Type `Terminal` and press **Enter**.
  3. Type `cd ` (make sure there is a space after "cd").
  4. Drag and drop the "Meme Hologram" folder from your desktop/finder right into the terminal window, then press **Enter**.

---

## ⚙️ Step 3: Setup the Project

Now that your black terminal window is open and you are inside the project folder, we need to download the final pieces.

1. In the terminal window, type the following command exactly as shown:
   ```bash
   npm install
   ```
2. Press **Enter**. 
3. Wait a minute or two. You will see some text scrolling by as it downloads the necessary files. When it stops and shows your folder name again, it's done!

---

## 🚀 Step 4: Run the Hologram!

Now for the fun part! Let's start the app.

1. In the same terminal window, type:
   ```bash
   npm run dev
   ```
2. Press **Enter**.
3. You will see some text appear. Look for a line that looks something like this:
   `➜  Local:   http://localhost:5173/`
4. This is your personal link! You have two ways to open it:
   - **Method A:** Hold down the `Ctrl` key (or `Command ⌘` on Mac) on your keyboard and click that link (`http://localhost:5173/`).
   - **Method B:** Select the link text, copy it, open your web browser (like Chrome, Edge, or Safari), paste it into the web address bar at the top, and press Enter.

🎉 **Congratulations!** The Meme Hologram should now be running in your web browser!

---

## 🛑 How to Stop It

When you are done playing with the hologram and want to close it, just go back to that black terminal window and press `Ctrl + C` on your keyboard. It will ask if you want to terminate the batch job, type `Y` and press Enter, or just close the terminal window completely.
